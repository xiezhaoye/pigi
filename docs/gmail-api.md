# 申请你自己的 Gmail API 凭据(OAuth 客户端 ID)

pigi 不经过任何服务器:邮件直接从你的电脑同步到 Gmail。Google 要求每个应用用 OAuth 客户端 ID 来表明身份,所以你需要在自己的 Google Cloud 里建一个(免费,约 10 分钟,只做一次)。

> 只想收发 Gmail 以外的邮箱?用 IMAP 添加即可,不需要这份文档。

## 你会得到什么

一串形如 `123456789012-abcdefg.apps.googleusercontent.com` 的客户端 ID。粘贴到 **设置 › 邮箱管理 › Gmail 客户端 ID**,之后就能正常添加 Gmail 账号。

## 准备

- 一个 Google 账号(用来建项目,可以和收信的账号不同)
- pigi 的 Bundle ID。直接用发布版就是 `site.xiezhaoye.pigi`;自己从源码编译并改过 Bundle ID 的,请填你自己的

## 第 1 步:新建项目

1. 打开 <https://console.cloud.google.com/>,登录。
2. 点左上角项目选择器 → **新建项目**。
3. 项目名随意(如 `pigi-mail`),**创建**,然后切换到这个项目。

## 第 2 步:启用 Gmail API

1. 左上角菜单 → **API 和服务 › 库**。
2. 搜索 `Gmail API`,点进去,点 **启用**。

## 第 3 步:配置 OAuth 同意屏幕

1. **API 和服务 › OAuth 同意屏幕**(新版界面叫 **Google Auth Platform › 品牌塑造 / 受众 / 数据访问**)。
2. 用户类型选 **外部**,**创建**。
3. 填写应用名称(如 `pigi`)、用户支持邮箱、开发者联系邮箱,保存。其余可留空。
4. **数据访问 / 范围**:添加范围 `https://www.googleapis.com/auth/gmail.modify`(查看、编辑邮件,但不能永久删除)。
5. **受众 / 测试用户**:把你要在 pigi 里使用的 **每一个 Gmail 地址** 加为测试用户。
6. 保持发布状态为 **测试中**,不需要提交 Google 审核。

> 测试状态下:最多 100 个测试用户;授权每 7 天过期一次,过期后在 pigi 里重新点一次登录即可。个人使用完全够用。

## 第 4 步:创建 OAuth 客户端 ID

1. **API 和服务 › 凭据 › 创建凭据 › OAuth 客户端 ID**。
2. 应用类型选 **iOS**(没有客户端密钥,正是 pigi 需要的)。
3. 名称随意;**Bundle ID** 填 `site.xiezhaoye.pigi`(或你自己的)。
4. **创建**,复制弹窗里的 **客户端 ID**。

## 第 5 步:粘贴到 pigi

1. 打开 pigi → 设置 › **邮箱管理**。
2. 把客户端 ID 粘贴到 **Gmail 客户端 ID**,出现对勾即格式正确。
3. **添加邮箱 › Gmail**,在浏览器里选择账号并同意授权。
4. 看到「此应用未经 Google 验证」时点 **高级 › 前往 pigi(不安全)**:这是你自己的应用,Google 对测试中的应用都会这样提示。

完成后邮件开始同步,默认拉取最近 30 天。

## 常见问题

**授权后提示 `redirect_uri_mismatch` 或 400?**
客户端类型必须是 **iOS**,Bundle ID 必须与你运行的 pigi 完全一致。

**提示「访问被拒绝 / 未通过验证」?**
你登录的地址没加入测试用户,回第 3 步第 5 点添加。

**一周后又要求登录?**
测试状态的刷新令牌 7 天有效,属于 Google 的限制,重新登录即可。想避免,需要把应用发布为「生产」并通过 Google 对敏感范围的审核,个人使用不建议。

**我的邮件会经过谁?**
只在 你的电脑 ↔ Google 之间传输,令牌存在 macOS 钥匙串,邮件存在本机数据库。
