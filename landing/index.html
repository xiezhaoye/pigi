三件顺手的事

少一点切换,
多一点时间。

为每天都要收一堆邮件的人设计:账号再多,也只看一条时间线。

01 · 多账号管理

所有邮箱,
汇成一条时间线。

Gmail 与 IMAP 邮箱可以同时添加,按时间混排在一起,也可以点左侧只看某一个。每个账号独立同步,互不影响。

  • Gmail 官方 API:增量同步,速度快
  • IMAP:iCloud、Outlook、Fastmail、自建邮箱都能连
  • 分组可折叠,未读数一目了然
  • 全局搜索跨账号,支持中文子串

02 · 退订与验证码

退订不再翻到页脚,
验证码不再手抄。

pigi 读懂邮件里的 List-Unsubscribe,有一键退订就直接发出请求并归档;没有就为你打开退订页。登录验证码会直接标在列表里,点一下复制。

  • 支持 RFC 8058 一键退订,发完自动归档
  • 只对公网地址发起请求,不碰内网
  • 验证码自动识别,列表中直接显示
  • 复制后弹出提示,切回浏览器粘贴即可

03 · 高效操作

在任何 App 里,
按下 ⌃⌥M。

菜单栏面板由全局快捷键唤起,不用切窗口就能看未读、复制验证码、退订、归档。列表里 J / K 上下移动,E 归档,S 星标,全部可以在设置里改成你顺手的键。

  • 全局快捷键唤起菜单栏面板(默认 ⌃⌥M)
  • J / K / E / S / ⌫ 键盘即可处理一封邮件
  • 所有快捷键可自定义,冲突自动提示
  • 新邮件通知,可选隐藏 Dock 图标

开始使用

两种方式接入邮箱。

pigi 没有服务器,所以账号直接在你的 Mac 和邮件服务商之间建立连接。

IMAP

填地址和密码。

设置 › 邮箱管理 › 添加邮箱 › 其他邮箱 (IMAP)。填入邮箱、应用专用密码和服务器地址,几秒钟就连上。密码存在钥匙串。

Gmail

用自己的 OAuth 客户端。

Gmail 需要你在 Google Cloud 里建一个免费的 OAuth 客户端,约 10 分钟、只做一次。按教程一步步来,把客户端 ID 粘贴进设置即可。

本地

数据留在你的 Mac。

邮件存在本机数据库,令牌存在钥匙串。没有统计、没有中转,卸载应用即清除一切。详见隐私政策。

开始之前

你可能想知道。

安装包没有公证,怎么打开?

解压后把 pigi 拖进「应用程序」。第一次打开如果提示无法验证开发者,请打开「系统设置 → 隐私与安全性」,在页面下方点「仍要打开」,再确认一次即可。之后就和普通应用一样。你也可以直接从 GitHub 获取源码自己编译。

我的邮件会经过 pigi 的服务器吗?

不会。pigi 没有服务器。应用直接连接 Google(Gmail API)或你填写的 IMAP 服务器,邮件和凭据只保存在你的 Mac 上。

需要什么权限?

网络访问(同步邮件)、通知(新邮件提醒,可关闭)、辅助功能不需要。钥匙串用于保存令牌和 IMAP 密码。

为什么 Gmail 要自己申请 OAuth 客户端?

读写邮件属于 Google 的受限权限,公开发布需要付费的第三方安全评估。开源版改为让你使用自己的客户端,数据完全由你掌控。步骤见申请教程。

支持发信吗?

暂不支持。当前版本专注于收信与整理:查看、归档、删除、星标、搜索、退订。

IMAP 是实时的吗?

目前每分钟检查一次新邮件,暂未使用 IDLE。Gmail 同样每分钟增量同步。
